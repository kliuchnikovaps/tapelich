Project context

A personal learning project for retrieving and summarising a small set of articles on a user-selected topic.

Approach

The workflow separates finding candidate articles, ranking their relevance and generating summaries. A simple input-and-results interface connects the user’s topic to a digest of five selected articles.

What I explored

The project links information retrieval to language-model summarisation. Relevance selection and summary quality are separate concerns: a fluent summary is only useful if it represents a relevant source accurately.

Preserved from my earlier portfolio for a complete record of the project. These historical notes include the original wording, code sketches and reported measurements, which have not been revalidated here. The edited case study above is the current overview.

Overview A Top-5 Article Summarization Agent finds and summarizes the most relevant articles on a user-specified topic. It retrieves articles through web scraping or news APIs, ranks them by relevance, and uses models like GPT for summarization. Key features include a ranking system based on topic relevance and a simple interface for input and viewing summaries. It’s uses Hugging Face models for natural language processing.
