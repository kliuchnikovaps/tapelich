# Как обновлять сайт

Сайт остаётся обычным статическим сайтом для GitHub Pages. Все HTML-страницы уже собраны: для просмотра достаточно открыть `index.html`, для публикации — обновить файлы репозитория.

## Где что находится

- `content/site.mjs` — имя, контакты, опыт, навыки, публикации и выступления.
- `content/projects.mjs` — все проекты, их описания, методы, ссылки и порядок в каталоге.
- `content/original-notes.json` — сохранённые подробные заметки со старого сайта. Они раскрываются внутри соответствующих проектов.
- `css/portfolio.css` — оформление и мобильная версия.
- `assets/documents/Polina_Kliuchnikova_CV.pdf` — резюме по кнопке Download CV.
- `assets/documents/conferences/` — сертификаты и другие документы выступлений.
- `assets/jpeg/conferences/` — фотографии с конференций; оригинал снимка открывается по ссылке под кадром.
- `profile.portrait` в `content/site.mjs` — портрет на главной и его размеры. Версия с прозрачным фоном находится в `assets/png/profile3-cutout.png`, исходник — в `assets/jpeg/profile3.jpg`.
- `scripts/build.mjs` — сборка HTML из содержимого.

## Как добавить видео и презентацию когнитивной конференции

1. Открой `content/site.mjs` и найди `id: 'cogsci-2026'`.
2. Заполни `video` ссылкой на запись, а `slides` — ссылкой на презентацию. Можно использовать адрес файла внутри сайта, например `assets/documents/cogsci-2026.pdf`.
3. Если используешь файл, положи его по указанному пути.
4. Пересобери сайт. Пока поле пустое, соответствующей кнопки на странице нет.

Пример:

```js
video: 'https://example.com/my-talk',
slides: 'assets/documents/cogsci-2026.pdf',
```

Так же добавляются материалы других выступлений. Не меняй `id`, если важно сохранить старую ссылку на страницу.

У `cogsci-2026` также заполнены `certificate`, `photo`, `photoAlt` и `photoCaption`. Они показывают сертификат МАКИ и фотографию на странице доклада. Кадрирование фото задаётся стилем `.conference-photo img`; исходный файл остаётся полным.

## Как отредактировать проект

В `content/projects.mjs` у каждого проекта есть:

- уникальный `id`, который задаёт адрес страницы;
- категория и название;
- краткое описание для каталога;
- список инструментов;
- разделы подробного описания;
- роль, период, ссылки и при наличии ключ исходных заметок.

Признак `featured: true` отмечает четыре проекта на главной. Чтобы поменять подборку, перенеси этот признак на другой проект. На главной должно остаться четыре таких проекта.

## Сборка и проверка

Нужен Node.js 18 или новее. Дополнительные библиотеки устанавливать не требуется.

```sh
npm run build
npm run check
npm run preview
```

Предпросмотр откроется по адресу `http://127.0.0.1:4173/tapelich/`.

После изменения `content` нужно выполнить сборку: браузер и GitHub Pages показывают готовые HTML-файлы. Для смены цветов или отступов в CSS пересборка не нужна.

## Каталог и подробные заметки

`projects.html` содержит все 35 проектов и направлений работы, включая 8 кейсов Huawei. Фильтры работают по компании/области, поиск — по названиям, описаниям и инструментам. Выбранный фильтр и поисковый запрос сохраняются в адресе страницы.

На странице Research раздел публикаций ведёт в Google Scholar, а раздел математических работ и зарегистрированных программ — в ИСТИНУ. Подробные научные кейсы остаются в общем каталоге проектов.

На страницах старых проектов есть блок `Original project notes`. В нём сохранён исходный подробный текст, включая русские заметки и прежние численные результаты. Отредактированное описание расположено выше. Архивные цифры не выдаются за повторно проверенные результаты.

Кнопка `Print / save as PDF` печатает страницу в упрощённом оформлении. Чтобы включить в печать исходные заметки, сначала раскрой их.

## Публикация на существующем GitHub Pages

В репозиторий нужно передать изменённые и новые файлы, включая собранные HTML-страницы и каталог `assets`. Адрес проекта и относительные ссылки сохранены. Настройку источника Pages менять не требуется, если сейчас сайт публикуется из корня ветки `main`.

Перед публикацией проверяй `npm run check`. Старые адреса страниц Сбера, VK, выступлений и исследований работают; отсутствовавшие страницы добавлены. Файл `.nojekyll` разрешает прямую публикацию статических файлов.
