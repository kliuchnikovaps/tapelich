The problem

Effective elastoplastic behaviour changes with the imposed deformation. Estimating it requires solving local boundary-value problems and averaging the resulting response over a representative material area.

My contribution

I am a coauthor of registered software RU 2020667788 for numerical estimation of effective elastoplastic characteristics in two dimensions.

Method

The implementation uses finite differences on a regular grid and an explicit time scheme. A dynamic relaxation process is used to approach a static solution.

The stress tensor is averaged over the representative area to obtain effective bulk and shear moduli at different deformation levels. CUDA supports parallel computation on the GPU.

Result

A registered computer program, RU 2020667788 (2020), connecting numerical methods, computational mechanics and parallel implementation.

Original project notes Detailed reference

Preserved from my earlier portfolio for a complete record of the project. These historical notes include the original wording, code sketches and reported measurements, which have not been revalidated here. The edited case study above is the current overview.

Abstract The program implements a numerical assessment of the effective elastic-plastic characteristics of a heterogeneous material in a two-dimensional case. The effective characteristics are estimated by solving a number of boundary value problems of plasticity theory on a representative area of ​​the material in the form of a rectangle. The boundary value problems are solved numerically, using the finite difference method on a regular grid. An explicit time scheme is used. The transition from a dynamic problem to a static one is implemented using the establishment method. The solution of the static problem (stress tensor) is averaged over the area, after which the effective properties are calculated in the form of bulk compression and shear moduli depending on the level of applied deformations. The solution of static boundary value problems is parallelized on the GPU using CUDA technology.
